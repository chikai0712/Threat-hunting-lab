## 容量與保存

| 參數 | 單位 | 結果 |
| --- | --- | --- |
| 平均／峰值輸入 | events/sec | 待確認 |
| 平均／最大事件大小 | bytes/event | 待確認 |
| 最長離線緩衝時間 | seconds或hours | 待確認 |
| Raw保存週期 | days | 待確認 |
| 搜尋索引保存週期 | days | 待確認 |
| 案件／證據／audit保存 | days或政策 | 待確認 |
| 查詢並行與時間範圍 | concurrent queries、days | 待確認 |
| 接收至可搜尋／告警延遲 | seconds | 待確認 |
| 備份、RPO／RTO | 時間及政策 | 待確認 |

估算式（只作初估，不是容量承諾）：

- 每日原始bytes ≈ 平均EPS × 平均bytes/event × 86,400。
- 離線buffer bytes ≈ 設計EPS × 平均bytes/event × 離線秒數 × 預留係數。
- 實際磁碟需再納入索引放大、replica、壓縮、raw副本與headroom；係數需以樣本量測。
